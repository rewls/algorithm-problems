== 접근

=== Balanced tree

stem:[M]은 문자열 최대 길이, stem:[N]은 문자열 개수

시간 복잡도::
stem:[O(N(M + \log N))]
공간 복잡도:: stem:[O(MN)]

=== Hash table

stem:[M]은 문자열 최대 길이, stem:[N]은 문자열 개수

시간 복잡도:: 평균 stem:[O(MN))]
공간 복잡도:: stem:[O(MN)]

=== Sorting

stem:[M]은 문자열 최대 길이, stem:[N]은 문자열 개수

시간 복잡도:: stem:[O(NM\log M)]
공간 복잡도:: stem:[O(MN)]
