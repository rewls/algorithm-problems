* stem:[a]: 리스트 시작부터 사이클 시작까지 거리
* stem:[b]: 사이클 시작부터 만난 지점까리 거리
* stem:[c]: 만난 지점부터 사이클 시작까지 거리
* stem:[L]: 사이클 길이, stem:[L = b + c]
* stem:[n]: 사이클 더 돈 횟수

[stem]

a = nL - b \\
a = (n - 1)L + c
